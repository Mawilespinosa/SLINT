Plantilla base

Estructura común para las 16 interfaces de SLINT. Copia este esqueleto, ajusta data-pagina y agrega el contenido dentro de <main>.

Pasos para crear una interfaz

  1. 1 Copiar esta plantilla como nombre-pagina.html.
  2. 2 Cambiar data-pagina por el código INT correspondiente.
  3. 3 Escribir el contenido semántico dentro de <main id="contenido">.
  4. 4 Agregar el script de página en js/paginas/ con defer.
  5. 5 Reutilizar las clases de styles.css y los componentes de componentes.html.
