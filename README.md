# SLINT

Sistema web para la gestión de turnos laborales y la liquidación de horas.

## Descripción
SLINT es un proyecto de software orientado a facilitar la administración de horarios, turnos partidos, control de novedades y cálculo de horas laborales y recargos. Busca mejorar la organización y trazabilidad de la información de una empresa.

## Funcionalidades previstas
- Gestión de usuarios y roles.
- Gestión de empleados.
- Registro de turnos con cuatro campos horarios para jornadas partidas.
- Importación masiva de turnos desde Excel.
- Validación de horarios.
- Liquidación de horas ordinarias, extras y recargos.
- Dashboard con indicadores y gráficos.
- Administración de parámetros laborales.

## Tecnologías
- HTML, CSS y JavaScript: prototipo de interfaz.
- PHP y Laravel: backend proyectado.
- MySQL: base de datos proyectada.
- Laragon: entorno de desarrollo local.
- Git y GitHub: control de versiones.

## Estado actual
Prototipo inicial de interfaces con datos simulados. La lógica de negocio y la integración de base de datos están pendientes de implementación y validación.

## Ejecución del prototipo
1. Clonar el repositorio con `git clone https://github.com/Mawilespinosa/SLINT.git`.
2. Abrir la carpeta SLINT en VS Code.
3. Abrir `plantilla.html` u otra vista HTML disponible en el navegador.
4. Recorrer las pantallas del prototipo.
